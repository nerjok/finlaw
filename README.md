1) Suformuokite GenDI užklausą, kuri – vartotojui pateikus organizacijos ir jos veiklos apyrašus, sistema identifikuotų kokioje finansų rinkoje veikia organizacija, kokie pagrindiniai finansų teisės institutai reguliuoja jos veiklą ir, ar organizacijai reikalinga veiklos licencija ar įrašymas į specializuotus finansų įstaigų sąrašus
2) Suformuokite GenDI užklausą, kuri – vartotojui pateikus rolės pavadinimą ir trumpą aprašą, sistema sugeneruotų rolės apyrašą organizacijos kontekste, kuris būtų naudojamas tolesnėms užklausoms kurti.
